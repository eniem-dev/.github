# eniem.dev

Build faster. Ship smarter.

Eniem is a developer toolkit that gives you everything you need to go from idea to production — boilerplate, CLI, starters, and documentation, all in one place.

### What's inside

- **eniem-boilerplate** — Production-ready starter code to get you up and running
- **eniem-starters** — Example applications for specific use cases
